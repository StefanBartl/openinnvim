# openinnvim features

Grouped by what part of the tool they belong to, not by how recently they were added.

- **[CURRENT-INSTANCE.md](CURRENT-INSTANCE.md)** — "Open with Neovim (current instance)":
  finding the running instance, opening the file over RPC, and the new-instance
  fallback.
- **[NEW-INSTANCE.md](NEW-INSTANCE.md)** — "Open with Neovim (new instance)": the
  terminal it starts and what it passes.
- **[FOLDERS.md](FOLDERS.md)** — what a folder click does, and the `:Filetree` hand-over.
- **[DEFAULT-APPS.md](DEFAULT-APPS.md)** — the optional default-application registration
  with two exe launchers.

The entries themselves come from `install.ps1`; the registry keys are listed
in [../BINDINGS.md](../BINDINGS.md).
